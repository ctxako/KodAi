☑️ Subtask
Self-referencing
Not a separate entity

Cascade rules
Delete Habit → deletes its Completions. Projects become unlinked (habitId = null), tasks fall to "General" group.
Delete Project → deletes all Tasks in that project and their Daily Task Completions.
Delete Task → deletes its Daily Task Completions and any subtasks (child Tasks).

Progress tracking
Count of DailyTaskCompletion records within the timeframe window vs. challengeTarget.

Rendering: Normal position in project group (or anchored section if also anchored). Shows progress ring or "3/5" fraction. Can coexist with anchor toggle.
challengeTimeframe enum values
daily — reset every day (e.g. "read 3 chapters today")
weekly — Monday to Sunday window (e.g. "meditate 5x this week")
monthly — calendar month (e.g. "run 20x this month")
custom — fixed duration from challengeStartDate (future consideration)
Duration tracking flow
When tracksDuration = true and a task is completed:
1. Completion card appears (same as current spec)
2. Below the follow-up input, a duration prompt: "How long?" with quick-pick buttons (5m, 15m, 30m, 1h) or manual entry
3. Duration saved to the DailyTaskCompletion.duration field
4. Aggregated into Weekly Snapshot's totalDuration
